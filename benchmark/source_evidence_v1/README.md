# 构造证据输入

`zero_review.json` 由 `scripts/audit_benchmark_zeros.py` 生成，复核 88 个带质量标记的 SGSC 窗口、40 户。每条保存原文件哈希、窗口比对、相邻正读数、来源服务状态和日期；这些记录不能确定零读数发生的原因。

`input_evidence.json` 保存问卷与通知的协议证据、核查过的 SGSC 源表列名和文件哈希。文献中报告的项目费率仅作为追溯信息，未用于填充家庭样本。个体采集／送达时刻和逐户费率未核实的事实保留。

公开的构造脚本只依赖这些固定证据和 `baseline/v1/`，不需要访问研究工作区。原始资料仍遵循其各自来源许可，见根目录 `DATA_LICENSES.md`。
