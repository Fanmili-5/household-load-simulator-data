## 实际发现及修正

| 项目 | 上一版的问题 | 本轮处理 |
|---|---|---|
| 研究主线 | 先报数据量与代码，尚未把要检验的问题放到最前 | 明确问题是：给定同户七天历史后，画像与目标条件是否提供额外预测信息；增加简短阶段汇报提纲 |
| 构造适用范围 | 769 个累计端点和 W1 筛选的叙述容易被理解为三份数据共用 | 明确它们专用于 LIRNEasia；SGSC/iFlex 按原生区间电量构造，分别使用半小时／小时分辨率 |
| 时间覆盖与画像时效 | “问卷早于历史”说清了先后，但没量化画像有多旧；未列新增来源实际目标日期数 | 从公开文件重算：新增来源有 91 个目标日期；问卷距目标日 8—227 天、样本中位数 124 天。明确问卷“上周行为”指调查前一周 |
| 后续检验 | 写了“比较历史和画像”，但汇报结束后不清楚先做什么 | 增加尚未执行的最小方案：历史朴素预测→同模型有无画像→validation 选设置后冻结 test；快照年龄/回忆行为字段另作分析 |

## 检查结果

| 检查问题 | 结果与证据 |
|---|---|
| 数据量与实物一致吗 | 直接流式读取三份默认数据：SGSC 2,076/16,246；iFlex 314/2,071；LIRNEasia 410/6,325；总计 2,800/24,642。见 [可复算统计](REPORT_SELF_AUDIT_STATISTICS_20260909.json) |
| 422 与 410 是否矛盾 | 不矛盾。422 户/6,660 条通过同户与连续性条件；335 条零读数窗口隔离后为 410 户/6,325 条；12 户无保留窗口。所有原窗口仍在仓库 |
| 一条样本的来源、长度与单位讲清了吗 | 已明确同户联接、7+1 天、672/96 点、相邻累计读数差分 kWh；区分购电、整户计量和功率换算，并提供真实样例 |
| 三来源是否被夸成一个统一实验 | 总量明确是资源盘点；旧两来源 v1 冻结，新来源独立版本及评分。画像 schema、事件条件和计量范围存在差异 |
| 文献是否被当成具体规则的证明 | 参考表区分方法借鉴与自主设计；7+1、家庭划分和 24h 零读数规则未声称来自论文或已经最优 |
| 划分与指标是否可复现 | 新来源保留 4,309/911/1,105 条，按家庭固定分区；小时及原生指标有对应代码。既有发布核验记录含 32 项测试和评分恒等/偏移检查，不能把它们当模型成绩 |
| 有无明显未来信息混入 | 已发布验证检查全部窗口边界与 W1 日期；目标质量信息只在 metadata。问卷快照较旧的事实已补充，后续模型模板须明确其时间语义 |
| 能否说输入一定有用 | 不能。尚无模型比较结果；“字段齐全”只表示本任务所需来源可联接，不表示所有跳题字段无缺失或画像总是准确及时 |
| 能否说是在线预测或因果响应 | 不能。电表可得延迟未独立核实、筛选涉及目标读数；LIRNEasia 无实际事件标签；三份数据都不自动证明新方案反事实或同意 |
