# 怎样开始看关联性

这份数据可以帮助讨论两个不同问题：什么样的家庭用电更多，以及同一户在不同条件下的用电怎样变化。全天总量接近，不代表活动期间的变化也接近。

先在一个来源内查看字段覆盖、每户记录数和曲线，再选择可比较的活动。iFlex 有人数、供暖方式和小时实验价格；SGSC 有部分电器数量、活动类型和时段。两个来源不具备相同的家庭字段。

## 推荐的阅读顺序

1. 运行 `python3 scripts/read_data.py`，确认记录数和窗口时长。
2. 看汇总表中的画像字段空缺，以及每户有多少次活动；扩展画像在 `input.profile`，同户原始回答完整保存在 `metadata.profile_provenance.raw_answers`；清洗过程见 [画像更新说明](PROFILE_UPDATE_20260908.md)。
3. 比较家庭特征时，尽量固定活动日期、价格或活动类型及窗口。先看实际电量，再另看相对历史参考的偏离。
4. 回到完整曲线，区分总量和日内形状。合计电量相同的两户可能在不同时间用电。

同一户反复出现，不能把每条记录都当作独立家庭。做总体描述时可先按家庭汇总，让每户等权；推断分析则需要考虑家庭内相关性。SGSC 与 iFlex 的窗口、气候和供暖条件不同，不能直接把两份数据的总 kWh 混在一起计算一个相关系数。

## 一个分组查看的例子

以下代码只描述某一天不同家庭人数组的用电，不把它当作人数造成用电差异的证明。若不同实验组接受不同价格，应再按 `signal_id` 分组。

```python
import pandas as pd

df = pd.read_csv('tables/iflex_events.csv', dtype={'household_id': str})
day = df[df['event_date'] == '2020-02-11']
print(day.groupby(['signal_id', 'household_size'], dropna=False)
         .agg(households=('household_id', 'nunique'),
              mean_daily_kwh=('target_total_kwh', 'mean'),
              median_daily_kwh=('target_total_kwh', 'median')))
```

家庭历史用电有助于解释个体之间的规模差异。已有参考曲线仅在原流程完成估计的记录中提供，很多 SGSC 记录的参考为空；不要把空白填零后计算响应。要统一估计参考，需要先确定匹配日期、时段和活动日排除规则。

## 当前能得出的结论范围

价格变化、家庭特征和用电存在统计关系，不等于已经证明某项活动的净效果。天气、家庭习惯、供暖方式和受控供电都可能影响观测。SGSC 的表计类型作为附带字段保留，可用于检查两类家庭是否表现不同，无需先把它们拆成两个数据集。

SGSC 的 1,526 条 `profile_event_support_only_offer_product_missing` 记录缺辅助招募表产品字段。可以比较纳入与排除这些记录时的结果，但不能把它们统一说成活动未知。其余 258 条冲突或边界缺失记录已从数据文件中剔除。

未来 SFT 计划预测活动日完整 24 小时；这里的 SGSC 全量数据仍是原活动窗口。当前可以做关联探索，不能把 18,413 条候选数当作已完成的全天训练样本数。
