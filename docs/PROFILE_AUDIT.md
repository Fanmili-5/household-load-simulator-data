# 当前画像能否作为多电器家庭的构造基础

2026-09-07 复查。这里的 baseline 指以真实家庭为基础，构造多电器家庭模拟器的训练样本。按照这一用途，当前导出的部分设备资料加整户曲线，还不足以称为完整家庭 baseline。

## 当前文件实际覆盖了什么

本次按家庭去重检查全部记录：SGSC 2,078 户，iFlex 314 户；每户在现有多条活动记录中的导出画像一致。

| 来源 | 当前设备字段 | 当前不足 |
|---|---|---|
| SGSC | 冰箱、空调、干衣机、泳池泵 | 仅冰箱有数量；空调等没有数量；470 户干衣机回答为不使用，不能据此认定没有设备。现有家庭主表没有完整的洗衣机、洗碗机等设备清单。 |
| iFlex | 电暖器、电地暖、热泵、独立电热水器、电动或插混汽车 | 当前导出所有设备数量均为空，但部分数量实际上存在于原问卷；也未导出温度偏好和控制习惯等信息。 |

SGSC 的详细房型和燃气相关题在 1,093 户中缺失；归纳房型、气候区等字段另有值，不能把两个字段的覆盖混为一谈。设备字段存在于记录中，也不等于每户拥有该设备。

## iFlex 存在可补回的源信息

独立读取源 `survey1_questions.csv` 和 `survey1_answers.csv`，按 ID 与本次保留的 314 户关联，得到以下结果。这些内容尚未加入当前 GitHub 数据文件。

| 原字段 | 原问题内容 | 在保留家庭中的情况 |
|---|---|---|
| `q16.1` | 电动或插混汽车数量 | 115 户有数值，其中 99 户为 1 辆、16 户为 2 辆。其余未填不能统一当作零。 |
| `q10` | 通常舒适的客厅温度 | 314 户有数值回答。 |
| `q11` / `q12` | 少用房间是否更低温；夜间或无人时是否降温 | 314 户有回答。 |
| `q13` | 是否及如何控制供暖 | 314 户有回答，包含不控制、手动、定时及按价格控制。 |
| `q14b` | 热水器控制方式 | 271 户有非缺失回答。 |
| `q9N4` / `q9N5` | 地热供暖、壁炉或木炉 | 原问卷提供主供暖、辅助供暖、不使用的区别，当前设备列表未包含这些字段。 |
| `q16b2_1` / `q16b3_1` / `q16b4_1` | 第一辆车的充电频率、常用时段及控制方式 | 115 户有非 NA 回答，但其中含 `-`、不确定等选项；它们不等于全部已知。第二、第三辆车有各自问题，后续应逐车映射。 |

因此，“iFlex 没有设备数量”不能作为来源结论；准确说法是当前抽取没有保留原问卷的车辆数量。SGSC 主表和 iFlex Survey 1 也不能据这些补充就称为完整家电清单。SGSC 的其他表（如 HAN）是否能给当前同一批家庭补充设备，仍需单独核对覆盖、时间和计量。

## 对后续构造的影响

整户实测曲线约束家庭整体用电；它没有直接标明每台设备在各时段用了多少电。拥有某设备、报告某种习惯，也不等于观察到了该次活动中的设备动作。

如果模拟器需要描述或调整多种设备，首先要明确实际建模的设备范围，再检查这些设备的持有、数量、用途或使用习惯等信息。没有必要罗列家中每一个小电器；但被明确建模的设备不能靠缺失值和总电量任意补造，其余用电可以在明确说明下作为背景负荷。

下一步应先补回同户原问卷中确实存在的信息，再列出原始来源无法提供的字段。外部匹配、设备分解或仿真补充若被采用，应标明估计或构造部分，不能称为同户实测。现有整户观测可保留作参考，但尚不能保证模型学到设备层的行为。

本次只复核画像并更正说明，未重写曲线、补造设备、生成 SFT 或训练模型。
