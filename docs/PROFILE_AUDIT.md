# 画像提取复核记录

本页保留 2026-09-07 的字段遗漏检查，并记录 2026-09-08 的修复结果。核对范围限于当前保留家庭的来源表，不表示源数据包含完整家电配置。

## 当前文件实际覆盖了什么

本次按家庭去重检查全部记录：SGSC 2,078 户，iFlex 314 户；每户在现有多条活动记录中的导出画像一致。

| 来源 | 当前设备字段 | 当前不足 |
|---|---|---|
| SGSC | 冰箱、空调、干衣机、泳池泵 | 仅冰箱有数量；空调等没有数量；470 户干衣机回答为不使用，不能据此认定没有设备。现有家庭主表没有完整的洗衣机、洗碗机等设备清单。 |
| iFlex | 电暖器、电地暖、热泵、独立电热水器、电动或插混汽车 | 旧版遗漏的车辆数量、温度偏好和控制习惯已补入；增加地热、木炉等其他供暖方式。其他设备的未知数量仍不填造。 |

SGSC 的详细房型和燃气相关题在 1,093 户中缺失；归纳房型、气候区等字段另有值，不能把两个字段的覆盖混为一谈。设备字段存在于记录中，也不等于每户拥有该设备。

## iFlex 存在可补回的源信息

独立读取源 `survey1_questions.csv` 和 `survey1_answers.csv`，按 ID 与本次保留的 314 户关联，得到以下结果。下列已知信息现已加入 iFlex 的扩展画像及原始回答追溯区。

| 原字段 | 原问题内容 | 在保留家庭中的情况 |
|---|---|---|
| `q16.1` | 电动或插混汽车数量 | 115 户有数值，其中 99 户为 1 辆、16 户为 2 辆。其余未填不能统一当作零。 |
| `q10` | 通常舒适的客厅温度 | 314 户有数值回答。 |
| `q11` / `q12` | 少用房间是否更低温；夜间或无人时是否降温 | 314 户有回答。 |
| `q13` | 是否及如何控制供暖 | 314 户有回答，包含不控制、手动、定时及按价格控制。 |
| `q14b` | 热水器控制方式 | 271 户有非缺失回答。 |
| `q9N4` / `q9N5` | 地热供暖、壁炉或木炉 | 原问卷提供主供暖、辅助供暖、不使用的区别，当前设备列表已补入这些字段，保留供暖用途。 |
| `q16b2_1` / `q16b3_1` / `q16b4_1` | 第一辆车的充电频率、常用时段及控制方式 | 115 户有非 NA 回答，但其中含 `-`、不确定等选项；它们不等于全部已知。已按车辆序号分别保存；第三辆车的细节在当前保留家庭中全部无回答。 |

因此，“iFlex 没有设备数量”不能作为来源结论；这是旧抽取遗漏的问题，现已把原问卷中的车辆数量补回。SGSC 主表和 iFlex Survey 1 也不能据这些补充就称为完整家电清单。SGSC 的其他表（如 HAN）是否能给当前同一批家庭补充设备，仍需单独核对覆盖、时间和计量。
